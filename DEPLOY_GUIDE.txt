========================================
  COMPLETE DEPLOYMENT GUIDE
  Celebrity Engagement Platform
========================================

STEP 1 — INSTALL GIT (if not installed)
-----------------------------------------
1. Go to: https://git-scm.com/download/win
2. Download and install (keep all defaults)
3. Restart your terminal/PowerShell after install


STEP 2 — CREATE GITHUB REPOSITORY
------------------------------------
1. Go to: https://github.com
2. Sign in (or create account)
3. Click "+" → "New repository"
4. Name it: celeb-platform
5. Set to Public or Private
6. DO NOT check "Add README" or any other options
7. Click "Create repository"
8. Copy the URL shown (e.g. https://github.com/yourusername/celeb-platform.git)


STEP 3 — PUSH CODE TO GITHUB
------------------------------
1. Open PowerShell in: C:\Users\saich\Desktop\celeb
2. Run these commands one by one:

   git init
   git add .
   git commit -m "Initial production deployment"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/celeb-platform.git
   git push -u origin main

   (Replace YOUR_USERNAME with your GitHub username)


STEP 4 — MONGODB ATLAS NETWORK ACCESS
---------------------------------------
1. Go to: https://cloud.mongodb.com
2. Click your project → Network Access
3. Click "Add IP Address"
4. Click "Allow Access from Anywhere" (adds 0.0.0.0/0)
5. Click Confirm


STEP 5 — DEPLOY BACKEND ON RENDER
------------------------------------
1. Go to: https://render.com → Sign in
2. Click "New +" → "Web Service"
3. Connect GitHub → Select your "celeb-platform" repo
4. Fill in:
   - Name: CelebBackend-4
   - Region: Singapore (or closest to you)
   - Root Directory: CelebBackend-main
   - Runtime: Node
   - Build Command: npm install
   - Start Command: node server.js
   - Plan: Free
5. Click "Advanced" → Add Environment Variables:
   (Copy from RENDER_ENV_VARS.txt — BACKEND section)
6. Click "Create Web Service"
7. Wait for deploy (2-3 minutes)
8. Copy your backend URL (e.g. https://CelebBackend-4.onrender.com)


STEP 6 — DEPLOY FRONTEND ON RENDER
-------------------------------------
1. Click "New +" → "Static Site"
2. Connect same GitHub repo
3. Fill in:
   - Name: celeb-frontend
   - Root Directory: CelebFrontend-master
   - Build Command: npm install && npm run build
   - Publish Directory: build
4. Add Environment Variable:
   (Copy from RENDER_ENV_VARS.txt — FRONTEND section)
5. Click "Create Static Site"
6. Wait for deploy (3-5 minutes)
7. Your site is live at: https://celeb-frontend.onrender.com


STEP 7 — VERIFY DEPLOYMENT
----------------------------
1. Open: https://celeb-frontend.onrender.com
2. Check celebrities load on home page
3. Try admin login at /adminLogin
4. Try adding a celebrity


TROUBLESHOOTING
----------------
- Backend not connecting to DB?
  → Check MongoDB Atlas Network Access (Step 4)
  → Verify MONGO_URI in Render env vars

- Frontend shows blank page?
  → Check REACT_APP_API_URL in Render env vars
  → Make sure it ends with /api

- Images not loading?
  → Render free tier doesn't persist uploaded files
  → For production, use Cloudinary or AWS S3 for image storage

- Slow first load?
  → Free tier spins down after 15 min inactivity
  → First request takes ~30 seconds to wake up
  → Upgrade to Starter ($7/mo) to avoid this
